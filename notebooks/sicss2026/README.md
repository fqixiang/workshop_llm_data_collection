# SICSS 2026 Notebooks on Data Collection/Annotation & Inferences with LLMs in Social Sciences

This folder contains the Python and R notebooks specifically designed for [SICSS 2026](https://sicss.io). You can choose either the Python or R notebooks based on your preference. The notebooks are organized in a way to guide you through the process of using large language models (LLMs) for data collection/annotation and inferential regression analysis in social sciences and humanities.

Use the notebooks in this order:
1. `sicss_llm_data_collection_py.ipynb` or `sicss_llm_data_collection_r.ipynb` - Notebook for familiarizing yourself with data collection/annotation using LLM APIs. **Internet access is required**. 
2. `sane_llm_data_collection_py.ipynb` or `sane_llm_fine_tuning_r.ipynb` - Notebooks for API-based data collection/annotation using locally deployed open-weights LLMs. These notebooks do not require internet access and are designed to be run on your local machine. You can choose either the Python or R notebook based on your preference.
2. `llm_inferential_regression_py.ipynb` or `llm_inferential_regression_r.ipynb` - Notebook for learning how to use LLMs for inferential regression analysis. Internet access is required to run these notebooks. You can choose either the Python or R notebook based on your preference.


*Note*: For users of RStudio, use the `.qmd` files instead of the `.ipynb` files. The `.qmd` files are Quarto notebooks that can be run in RStudio, while the `.ipynb` files are Jupyter notebooks that can be run in Jupyter Notebook or JupyterLab.
